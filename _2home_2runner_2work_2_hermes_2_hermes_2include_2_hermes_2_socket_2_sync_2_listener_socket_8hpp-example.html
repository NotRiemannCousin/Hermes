Returns a generator that accepts connections until the listener closes.

Returns a generator that accepts connections until the listener closes. Each yielded value contains either an accepted ServerSocket or an accept error. Transfer options are applied later to operations on each yielded ServerSocket; they are not options for AcceptAll().

The generator runs until Close() is called or a non-recoverable error occurs.

for (auto&& result : listener.AcceptAll()) { if (!result) { /* log error *‍/ continue; } handle(std::move(*result)); }
