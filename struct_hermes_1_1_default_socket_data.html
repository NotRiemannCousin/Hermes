struct Hermes::DefaultSocketData< ExecutionContext, Endpoint, SocketType, SocketFamily >

A basic data class for general propourse sockets (sync and async).

It provides a generic class designed to serve as a data storage to simple socket types.

template<class ExecutionContext = std::monostate, EndpointConcept Endpoint = IpEndpoint, SocketTypeEnum SocketType = SocketTypeEnum::Stream, AddressFamilyEnum SocketFamily = AddressFamilyEnum::Inet6>
ExecutionContextType Hermes::DefaultSocketData< ExecutionContext, Endpoint, SocketType, SocketFamily >::executionContext {}

The execution context for async sockets.

In IO operations, ideally your execution context state is stored somewhere else with a longer lifetime than the sockets that uses it, so this data class stores a non-owning reference of this execution context.

Note
This is a pointer unless ExecutionContext is a std::monostate. In that case, this member is a std::monostate with no unique address.
Warning
It's a raw pointer so the value can be nullptr. This is the default value, your classes needs to deal with that.
